Лабораторна робота №5 – безпека API

OAuth 2.0 Authorization Code flow через Keycloak (OIDC).

Після входу gateway обміняє code на JWT і перевірить scopes.

Тестовий користувач Keycloak: student / student

Login with Keycloak

Для мінімального балу в Keycloak Admin можна додати Identity Provider (Google / GitHub / Atlassian) – кнопка Login with … з’явиться на формі входу.

Корисні посилання

  • /api/security/info
  • /api/cors-check (CORS для cad.kpi.ua)
  • Keycloak Admin (admin / admin)
